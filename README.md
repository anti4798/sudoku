# 🧩 Classic Sudoku ✨

> 숫자 아홉 친구들이 사이좋게 자리 찾는 게임이에요! 🐣

브라우저만 있으면 바로 즐길 수 있는 귀여운 스도쿠 한 판 🍀
설치도, 빌드도 필요 없어요. 파일 하나로 끝! 📄

## 🚀 시작하기

```bash
open index.html   # 또는 그냥 더블클릭! 🖱️
```

## 🎮 이렇게 놀아요

| 하고 싶은 것 | 방법 |
| --- | --- |
| 🎯 칸 고르기 | 칸을 클릭하거나 방향키 ⬆️⬇️⬅️➡️ |
| 🔢 숫자 넣기 | 숫자 패드 클릭 또는 키보드 `1`~`9` |
| 🧽 지우기 | `지우기` 버튼, `Backspace`, `Delete`, `0` |
| 🔍 오류 검사 | `오류 검사 (Check)` 버튼 |
| 🌱 새 게임 | `새 게임` 버튼 |

## 📝 똑똑한 메모 기능

- 한 칸에 숫자를 **여러 개** 넣으면 작은 메모로 쏙 들어가요 ✏️
- 같은 **줄**이나 **3×3 박스**에 이미 있는 숫자를 넣으면, 크게 들어가지 않고 메모로 살짝 들어가요 🙈
- 겹치던 숫자를 지우면 메모가 다시 큰 숫자로 짠! 바뀌어요 🎉
- 같은 숫자는 은은하게 하이라이트돼서 찾기 쉬워요 🔦
