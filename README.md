# 🧩 스도쿠 ✨

![스도쿠 미리보기](og-image.png)

> 숫자 아홉 친구들이 사이좋게 자리 찾는 게임이에요! 🐣

브라우저만 있으면 바로 즐길 수 있는 귀여운 스도쿠 한 판 🍀
설치도, 빌드도 필요 없어요. 파일 하나로 끝! 📄

## 🚀 시작하기

```bash
open index.html   # 또는 그냥 더블클릭! 🖱️
```

## 📱 앱처럼 설치하기

- 🤖 안드로이드 크롬: 접속하면 뜨는 `설치` 배너를 누르거나, 메뉴 ⋮ → `앱 설치`
- 🍎 아이폰 사파리: 공유 버튼 → `홈 화면에 추가`
- 한 번 열어 두면 인터넷이 없어도 플레이할 수 있어요 ✈️

## 🎮 이렇게 놀아요

| 하고 싶은 것 | 방법 |
| --- | --- |
| 🎯 칸 고르기 | 칸을 클릭하거나 방향키 ⬆️⬇️⬅️➡️ |
| 🔢 숫자 넣기 | 숫자 패드 클릭 또는 키보드 `1`~`9` |
| 🧽 지우기 | 같은 숫자를 한 번 더 누르면 쏙! (키보드 `Backspace`, `Delete`, `0`도 OK) |
| 🔍 정답 맞추기 | `정답 맞추기` 버튼 (겹치는 숫자는 빨갛게 알려줘요) |
| 🌱 새 게임 | `새 게임` 버튼 |
| 🎚️ 난이도 바꾸기 | 위쪽 `쉬움` / `보통` / `어려움` 버튼 (누르면 새 게임 시작!) |

## ⏱️ 타이머

- 처음엔 보드가 뿌옇게 가려져 있어요 🌫️ 미리 훔쳐보기 금지!
- `▶ 시작` 버튼을 누르면 보드가 짠 나타나고 타이머가 똑딱똑딱 흘러가요 🕰️
- 새 게임이나 난이도를 바꾸면 다시 가려지고 `00:00`부터 시작해요
- 퍼즐을 완성하면 멈추고, 축하 메시지에 기록이 같이 나와요 🏅

## 📝 똑똑한 메모 기능

- 한 칸에 숫자를 **여러 개** 넣으면 작은 메모로 쏙 들어가요 ✏️
- 같은 **줄**이나 **3×3 박스**에 같은 숫자가 겹치면, 먼저 넣은 숫자까지 **둘 다** 메모로 살짝 바뀌어요 🙈
- 겹치던 숫자를 빼서 하나만 남으면, 남은 숫자가 다시 큰 숫자로 짠! 바뀌어요 🎉
- 메모가 여러 개인 칸에서 하나만 남기고 다 빼도 큰 숫자가 돼요 ✨
- 같은 숫자는 은은하게 하이라이트돼서 찾기 쉬워요 🔦
